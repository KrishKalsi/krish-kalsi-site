Character:
A — Loading screen: one path (the cover itself has no walk)
  • Full-screen, page background. Counter 000 → 100 bottom-left in the wordmark style; KK© top-left; “Loading: one random walk, σ = 0.25” and the step count bottom-right.
  • One random walk draws left to right across the screen in step with the count (1.9 s), with a small dot at its tip and a faint dotted baseline. A new path each time.
  • At 100 the page opens as a circle from the tip of the path (0.95 s). About 3.1 s in total. No ring at the centre.
  • First visit of a session only. Any click, key or scroll skips it.
  • Skipped entirely under reduced motion. The page loads underneath, so content is never delayed.
  • Follows the visitor’s theme. The cover itself has no figure or animation.
B — Circle cursor
  • 16 px ring, 1 px, difference blend so it reads on any colour or photo.
  • Follows the pointer with light easing (22% per frame) — smooth, never laggy.
  • 40 px over links and buttons; 56 px and filled over Work items (inverts the text beneath).
  • Only on devices with a fine pointer (mouse/trackpad). Touch screens keep the normal behaviour.
  • Reduced motion: no easing trail, ring snaps to the pointer. Native text cursor kept in any text field.
C — Number scramble (on standby, not built)

Key numbers (90%, ≈ 21, 3,000+, 8.43) flicker through digits for ~400 ms before settling, once, when scrolled into view. Can be added later without changing anything else.
